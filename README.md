## I build tools that turn agent demos into useful workflows.

Computer use, everyday automation, and experiments that measure the whole workflow—not just the model call.

### Featured: [Jev Agent Router](https://github.com/ljy8072/jev-agent-router)

**Code when exact. Jev when useful. Agent when uncertain.**

A lightweight choice layer for existing computer-use agents. One local form-filling experiment went from **42.74 s to 5.32 s** with a batched Jev loop; the code-only control took **3.17 s**. The project includes the control, raw timings and limitations, because that is the useful part of the story.
